PS#1 · Creative HTTP Server · built on node:net

fs-forge

An HTTP/1.1 framework built from scratch on Node's net module — no http, no Express. The routes/ directory is the API: no registration, ever. This page is itself a route (routes/index.js → html()); its assets are served by the static handler.

Zero-config routing Tagged-template DSL Live hot reload Wire inspector

The filesystem is the router

routes/
├─ index.js ······· → /
├─ play.js ········ → /play
├─ world.js ······· → /world (ws)
└─ api/penguins/
   ├─ index.js · → /api/penguins
   └─ [id].js ·· → /api/penguins/:id

A route file reads like HTTP

// routes/api/penguins/[id].js
module.exports = http`
  PUT    ${({params}) =>
           json(rename(params.id))}
  DELETE ${() => noContent()}
`;
